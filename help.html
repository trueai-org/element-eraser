📖 Element Eraser 使用教程

1 分钟学会如何删除网页上的任何元素

🚀 快速开始（推荐新手）

最简单的方法：不需要懂 CSS 或 XPath！

  1. 点击插件图标
    在浏览器工具栏找到 Element Eraser 图标并点击
  2. 点击"开始选择元素"按钮
    使用默认设置即可（CSS + 隐藏模式）
  3. 鼠标移动到要删除的内容上
    例如广告、弹窗、推荐内容等，会出现红色边框
  4. 点击一下
    元素立即消失！规则自动保存
  5. 按 ESC 键退出
    完成操作
💡 小提示

刷新页面后，被删除的内容依然不会出现！插件会自动记住你的选择。

🎯 理解两种选择器类型

什么是 CSS 选择器？

CSS 选择器就像"地址"，告诉浏览器要找哪个元素。就像你告诉快递员"3号楼2单元501"一样简单。

选择器 含义 举例
#id名称 通过 ID 查找（最精确） #ad-banner 找到 ID 为 "ad-banner" 的元素
.类名 通过 class 查找 .advertisement 找到所有广告
标签名 通过 HTML 标签查找 iframe 找到所有 iframe
🌰 常见广告 CSS 选择器示例
#ad-container .adsbygoogle .advertisement [data-ad="true"] iframe[src*="doubleclick"]
✅ 推荐使用场景

• 删除广告和弹窗（90%的情况）
• 速度快，简单直观
• 适合新手

什么是 XPath？

XPath 像是"导航路线"，可以描述更复杂的查找方式。如果 CSS 找不到，可以用 XPath。

表达式 含义 举例
//*[@id="xxx"] 查找 ID 为 xxx 的元素 //*[@id="aswift_0"]
//div[@class="xxx"] 查找 class 为 xxx 的 div //div[@class="ad"]
//*[contains(@id, "ad")] 查找 ID 包含 "ad" 的元素 //*[contains(@id, "google")]
🌰 常见广告 XPath 示例
//*[@id="aswift_3_host"] //iframe[contains(@src, "ads")] //div[contains(@class, "advertisement")] //*[@data-ad-slot]
✅ 推荐使用场景

• CSS 选择器找不到元素时
• 需要更复杂的查找条件
• 动态生成的广告

🔍 如何获取元素的选择器？

方法一：使用浏览器开发者工具（推荐）

  1. 右键点击要删除的元素
    选择"检查"或"审查元素"
  2. 在开发者工具中找到高亮的代码
    这就是该元素的 HTML 代码
  3. 右键点击高亮代码
    选择 "Copy" → "Copy selector" 获取 CSS 选择器
    或选择 "Copy XPath" 获取 XPath
  4. 粘贴到插件的手动输入框
    点击"添加规则"即可
💡 快捷键

• Windows/Linux: 按 F12 打开开发者工具
• Mac: 按 Cmd + Option + I

方法二：使用插件自动生成（最简单）

直接点击"开始选择元素"，插件会自动生成最佳选择器，无需手动操作！

❓ 常见问题解答

Q1: CSS 和 XPath 应该选哪个？

A: 新手建议用 CSS 选择器，90% 的情况都够用。只有 CSS 找不到时才用 XPath。

Q2: "隐藏"和"删除"有什么区别？

A:

  • 隐藏：元素还在，只是看不见（推荐）
  • 删除：直接从网页代码中移除（用于顽固广告）

Q3: 为什么有时候删除不生效？

A: 可能是广告延迟加载。解决方法：

  • 等广告完全显示后再删除
  • 使用"删除模式"而不是"隐藏模式"
  • 刷新页面测试是否生效

Q4: 如何删除 Google Ads？

A: 常见的 Google Ads 选择器：

#aswift_0_host #aswift_1_host .adsbygoogle ins.adsbygoogle

CSS 选择器速查

/* 基础选择器 */
#id /* ID 选择器 */
.class /* 类选择器 */
element /* 标签选择器 */
/* 属性选择器 */
[attr] /* 有该属性 */
[attr="value"] /* 属性等于 */
[attr*="value"] /* 属性包含 */
/* 组合选择器 */
div.class /* div 且有 class */
div > p /* 直接子元素 */
div p /* 所有后代 */

XPath 速查

/* 基础表达式 */
//*[@id="xxx"] /* 通过 ID */
//div[@class="xxx"] /* 通过 class */
//tag[contains(@attr, "x")] /* 属性包含 */
/* 常用函数 */
contains(@attr, "text") /* 包含文本 */
starts-with(@attr, "text") /* 以...开头 */
text()="xxx" /* 文本等于 */
